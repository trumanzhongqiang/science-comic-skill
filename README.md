# 科普漫画 · science-comic-skill 🎨

给自媒体一键生成科普漫画的 Agent Skill：只需提供一个选题，自动完成选题理解、事实核查、分镜脚本、角色卡锚定、逐格出图与气泡文字后期合成，产出一整套可发布的漫画图片。

## 功能特性

- **选题理解**：接收选题或一段科普文案，提炼核心知识点，规划「悬念开场 → 层层拆解 → 总结升华」的叙事节奏
- **事实核查优先**：生成脚本前先检索核对知识点，来源可溯，避免「漫画很好看但知识是错的」
- **分镜脚本**：逐格输出画面描述、旁白与气泡对话，确认后再出图
- **角色卡锚定一致性**：先固化角色外观、配色与画风描述词，作为锚点贯穿所有镜头，跨格、跨连载期数形象不漂移
- **逐格出图**：自动生成每格图像提示词，处理多角色构图、表情与肢体动作
- **智能文字策略**：图像模型中文渲染不可靠，气泡与标题一律留空，由 AI 后期精准填字

## 快速开始（WorkBuddy 用户）

1. 克隆本仓库或下载 `science-comic-skill.skill` 打包文件
2. 在 WorkBuddy 中加载该 `.skill` 文件
3. 对助手说「启动科普漫画」，或直接给出选题，例如：
   > 把「为什么天空是蓝色的」做成 6 格漫画
4. 助手依次产出：知识卡 → 角色卡 → 分镜脚本（给你确认）→ 逐格图片 → 合成成品

## 工作方式

基于 Agent Skill 架构的一条流水线：

```
选题分析 → 事实核查 → 角色卡锚定 → 分镜脚本 → 逐格图像生成 → 气泡文字后期合成
```

三条核心设计原则：**科学准确性优先**、**角色一致性是生命线**、**同一张角色卡可复用到整个连载系列**。
