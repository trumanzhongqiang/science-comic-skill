# 交付说明模板

整组漫画合成后，按本模板写 `delivery-report.md`。四查各写一条结论，不能合并成「整体没问题」。

```markdown
# 交付说明：<选题>

## 产物
- knowledge-card.md
- characters.md
- storyboard.md
- panels/p01/panel-01.png …
- output/comic-final.png

## 成本
- 计划格数 / 实际生成次数 / 废片原因（漂移、丢图、语义画反、数量不足）

## 来源冲突
- 无。或：冲突点 / 各方口径 / 采用哪一家 / 理由 / 是否与该机构其他文件自洽

## 装读者四查

### 第一查 知识
- 结论：通过 / 未通过
- 证据：抽查了哪一格，对应知识卡编号
- 问题与回修：无，或回阶段 2

### 第二查 角色
- 结论：通过 / 未通过
- 证据：并排看了哪两格；体型、肤色、服饰是否一致
- 问题与回修：无，或加强具象形态级后回阶段 5 重画哪一格

### 第三查 文字
- 结论：通过 / 未通过
- 证据：气泡是否把话说清、字号是否可读；有无溢出、错字、孤行标点、水印压字
- 问题与回修：无，或回阶段 4/6

### 第四查 节奏
- 结论：通过 / 未通过
- 证据：30 秒只读每格首句，能否走完钩子 → 拆解 → 收束
- 问题与回修：无，或回阶段 4 拆格

## 重画记录
| 格 | 原因 | 处理 |
|----|------|------|
| 无 |  |  |
```
