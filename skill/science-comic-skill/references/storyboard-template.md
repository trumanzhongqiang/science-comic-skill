# 分镜脚本模板（Storyboard）

分镜脚本是连接「知识卡」和「逐格出图」的桥梁：它把知识点翻译成一格一格的画面、旁白和气泡对话，确认后才是出图的依据。

## 叙事节奏

整组漫画固定为三段式：

1. **悬念开场（第 1 格）**：抛出一个反直觉的问题或场景，制造「咦，为什么？」
2. **层层拆解（中间格）**：每格只讲透一个知识点，由浅入深；复杂知识拆成「现象 → 原理 → 例子」相邻格
3. **总结升华（末格）**：一句话收束 + 一个记忆点（类比、口诀或行动建议）

## 单格字段

| 字段 | 说明 |
|------|------|
| 格号 | P1、P2… |
| 景别 | 特写 / 中景 / 全景 |
| 画面描述 | 构图、角色动作与表情、场景、关键视觉元素 |
| 旁白 | 可选，格子顶部或底部的叙述文字 |
| 气泡 | 谁说的 + 一句能听懂的口语（常见一行 8–14 字） |
| 文字卡 | 放不下气泡的长句，后期画在留白区 |
| 对应知识点 | 引用知识卡编号，保证每格都有事实出处 |
| 情绪 | 本格的情绪基调（惊讶/认真/恍然大悟…） |

## 分镜脚本示例（6 格版式）

```markdown
# 分镜脚本：为什么天空是蓝色的？
画风：明快扁平卡通，粗描边，二头身 Q 版
主角：小盐（红色连帽衫讲解员）；配角：小海（蓝色背带裤提问者）

## P1｜全景｜情绪：疑问
- 画面：小海躺在草地上指着天空，小盐站在旁边。天空大面积留白，顶部预留空白标题位。
- 旁白：（留空，后期填「天空为什么是蓝色的？」）
- 气泡：小海：「天为啥是蓝的？」
- 知识点：K1（现象）

## P2｜特写｜情绪：认真
- 画面：小盐举起搅拌棒指向观众，背景为纯色。
- 气泡：小盐：「阳光是七色光叠在一起。」
- 知识点：K2（白光由多色光组成）

## P3｜中景｜情绪：演示
- 画面：小盐用手把一束光「拆」成七色，空中留白气泡。
- 气泡：小盐：「小颗粒把光拦住了。」
- 知识点：K3（瑞利散射）

## P4｜特写｜情绪：恍然
- 画面：蓝色光波被弹向四面八方的示意画面，小海瞪大眼睛。
- 气泡：小海：「所以满眼都是蓝。」
- 文字卡：蓝光最容易被散射。
- 知识点：K3（蓝光散射强）

## P5｜中景｜情绪：追问
- 画面：小海指着夕阳方向，天边留白。
- 气泡：小海：「傍晚怎么变红？」
- 知识点：K4（预留钩子）

## P6｜全景｜情绪：收束
- 画面：两人并肩看夕阳，画面下方预留空白总结位。
- 旁白：（留空，后期填「光走的路变长，蓝光散光光，红光留下来。」）
- 气泡：小盐：「蓝光爱散，红光爱穿。」
- 知识点：K4+K5（总结升华）
```

## 写作规则

1. **一格一知识点**：塞不下的知识拆成两格，不硬塞
2. **对话推动剧情**：用提问引出讲解，避免整格只有旁白说教
3. **气泡给模型留空**：脚本里写好文案，但出图提示词要求空白气泡，文字全部后期用 tools/compose.py 填
4. **气泡把意思说完**：不要砍成残句。出图时把空白气泡画大；数字和解释放文字卡。合成时若可读字号下放不下，换更大的气泡或改文字卡，不要缩字
5. **结尾必须落到记忆点**：口诀、类比或一句行动建议
6. **确认再出图**：脚本先给用户过目，改定后再进入逐格生成

## 格数速查

- 4 格：单知识点 + 一个现象反转
- 6~8 格：2~4 个知识点的标准科普（默认）
- 9~12 格：系列首期的完整讲解，适合公众号长图
